## 顶刊论文

### 1. 半拉格朗日自适应秩方法把 Vlasov 模拟推到六维  `数学与计算数学` `重要度 9/10`

**A Semi-Lagrangian Adaptive Rank Method for High-Dimensional Vlasov Dynamics**

作者把此前在有限差分框架下针对非线性 Vlasov–Poisson 系统的半拉格朗日自适应秩积分器，推广到一般高阶张量情形。技术上有三块：一是三阶高维多项式重构，为半拉格朗日格式在特征线足点提供逐点近似；二是基于层次 Tucker 格式（以张量树刻画）的高阶张量递归层次自适应交叉近似；三是层次 Tucker 格式下的低复杂度 Poisson 求解器，借 FFT 提效。计算出的自适应秩动理学解在张量树各分支内呈现低秩结构，从而在存储和时间上都有可观节省，整体复杂度随维数 d 与树中最大秩的增长被压住，绕开了维数灾难。

**为什么重要：** 高维动理学方程长期受制于「每维网格点数取幂」的存储爆炸，六维相空间模拟基本是禁区。这里的关键不是单个技巧，而是把半拉格朗日的大步长稳定性、张量低秩压缩和快速 Poisson 求解串成一条完整链路，使六维 Vlasov 模拟在复杂度上变得可行——对聚变等离子体与天体物理中的相空间输运计算是直接可用的路线。

<sub>来源：[1]  `半拉格朗日` `张量低秩` `Vlasov方程` `维数灾难`</sub>

### 2. 非局部聚集-扩散方程的格子 Boltzmann 方法及其二阶收敛证明  `数学与计算数学` `重要度 6/10`

**A Lattice Boltzmann Method and Its Convergence Analysis for Nonlocal Nonlinear Aggregation-Diffusion Equations**

做法是先把聚集-扩散方程（ADE）改写为带非局部通量和变扩散系数的对流-扩散方程，再对后者套用经典 LBM，但 equilibrium 分布改为非局部形式、松弛时间改为可变。平衡分布中的非局部空间卷积用二阶中点公式近似。收敛性证明结合碰撞算子的稳定性结构与渐近展开得到的辅助分布函数，主要难点在离散卷积，作者通过对二次误差项作基本分解来克服，最终证得二阶收敛。文中数值实验验证了二阶收敛，若干困难问题的结果与现有方法相当。该文获 SIAM 可复现徽章（代码与数据公开）。

**为什么重要：** 非局部聚集-扩散方程是描述群体行为、细胞黏附等过程的模型，此前 LBM 用于此类方程多停留在格式构造层面，缺少收敛性保证。这里补上了二阶收敛的严格证明，并给出可复现代码，使 LBM 成为该方程类一个有误差阶可依赖的求解选项。

<sub>来源：[2]  `格子Boltzmann` `非局部方程` `收敛性分析` `可复现`</sub>

### 3. 把概率流形降维扩展到参数化问题  `数学与计算数学` `重要度 6/10`

**Parametric Probabilistic Manifold Decomposition for Nonlinear Model Reduction**

前作 PMD 把高维动力学嵌入低维概率流形，在时间依赖系统上表现良好，但公式体系只针对时间演化，无法直接容纳参数变化，限制了其在设计优化、控制与不确定性量化中的应用。本文提出 PPMD，把概率流形嵌入与参数感知的潜变量学习结合，从而对未见参数值（如不同边界或初始条件）给出平滑预测，同时保留 PMD 的非侵入式流程。作者给出了覆盖线性主子空间近似、非线性解流形几何恢复、以及潜变量学习所用核岭回归统计一致性的收敛分析，并在圆柱绕流与后台阶流两个经典构型上做了数值验证，报告其在训练参数范围之外的精度与泛化优于对照。

**为什么重要：** 降维方法要真正进入工程设计回路，必须能对没算过的参数取值给预测，而不只是重建已算过的时间轨迹。PPMD 把「非侵入式」这一工程属性保留下来，同时补上参数维度，使代理模型的构建不必依赖侵入式改写求解器。

<sub>来源：[3]  `非线性降维` `参数化代理模型` `收敛分析`</sub>

### 4. 自适应有限元多重网格的 GPU 加速，最小改动换来最高 20 倍提速  `数学与计算数学` `重要度 6/10`

**An Adaptive Finite Element Multigrid Solver Using GPU Acceleration**

作者为自适应有限元库 Gascoigne 开发 GPU 加速，目标是在尽量少改现有代码的前提下接入。实现策略是把所有计算系统性地表述为线性代数运算，从而直接调用 GPU 加速线性代数库，既简化实现又保持代码可维护性，同时获得较高的 GPU 利用率。在输运-扩散方程、线弹性、非定常 Navier–Stokes 方程三组问题上，相对多核 CPU 实现报告了最高 20 倍的加速。该文获 SIAM 可复现徽章。

**为什么重要：** 自适应有限元加几何多重网格本是求解非定常流等问题最高效的数值路线之一，但实际模拟仍常需数小时到数天。这里值得注意的不是加速比数字本身，而是「把计算统一表述为线性代数以复用 GPU 库」这一改造路径——它让已有的大型自适应 FEM 代码有可能以低迁移成本获得 GPU 收益。

<sub>来源：[5]  `GPU加速` `自适应有限元` `多重网格` `可复现`</sub>
